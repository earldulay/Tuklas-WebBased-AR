# Tuklas AR Science Lab

Light mobile web-app draft for an offline-capable Grade 9 science POE lab.

The draft includes:

- A role picker for Student Mode and Teacher Mode.
- A bottom navigator with Home, Modules, and Settings.
- A Home dashboard with current module, progress summary, and current task.
- A searchable module library and module detail screen.
- A Predict, Observe in AR, Explain, and Result activity flow.
- A Newton's-law sample AR-style simulator with force, mass, and acceleration readouts.
- Local saved records with JSON export.
- A DepEd-inspired blue, red, gold, and white visual direction with mobile-first layout adjustments.
- A service worker and manifest for PWA/offline-readiness exploration.

Open `index.html` directly for the static draft. For service worker testing, serve the folder over localhost or HTTPS.
